# پذیرش فاز ۱

**وضعیت:** فایل‌های بنیاد آمادهٔ آزمون محلی هستند؛ تأیید اجرا نشده‌اند. موتور در محیط ابری نصب یا اجرا نشد.

بررسی ایستا: ارجاع منابع و شناسه‌های داخلی صحنه‌ها، نگاشت شش ورودی، اتصال صحنهٔ اصلی، منشأ فونت و مجوز آن. این بررسی جای parser، واردکنندهٔ منابع یا رندر Godot نیست.

## آزمون مالک روی Windows x64 / Godot 4.7.2 Standard

- [ ] Import بدون خطای script/resource؛ F5 نمای مسیر آزمایشی را باز کند.
- [ ] چهار جهت، حرکت مورب و تفاوت سرعت با Shift را امتحان کنید.
- [ ] چهار مرز را لمس کنید؛ دوربین به راست دنبال کند ولی خارج از نقشه نرود.
- [ ] به پایهٔ جعبه برخورد کنید و سپس جلو و پشت آن بروید؛ ترتیب نمایش با جای پا تغییر کند.
- [ ] در حرکت Esc بزنید؛ پیام توقف ظاهر شود، حرکت متوقف شود و Esc دوم کنترل را برگرداند.
- [ ] صحنهٔ فارسی را با F6 اجرا کنید؛ تصویر را برای اتصال حروف، راست‌چینی، اعداد فارسی، علائم و متن لاتین بررسی کنید.
- [ ] با قالب هم‌نسخه خروجی بگیرید؛ EXE را کنار PCK روی ویندوز بدون اینترنت اجرا کنید.

برای ثبت نتیجه، نسخهٔ کامل موتور، نسخهٔ ویندوز، نتیجهٔ هر مورد، تصویر آزمون فارسی و متن خطاهای Output/Debugger را نگه دارید. هیچ آزمون تعاملی یا headless و هیچ خروجی بومی در محیط توسعه انجام نشده است. نمایش بازیکن و محیط موقت‌اند؛ مبارزه و امکانات مراحل بعدی وجود ندارند.
