# PR #3 — Windows acceptance: art foundation freeze

The owner approved the Windows visual direction at V1.1. This checklist is for the **new cleanup revision**, which has not been run on Windows by the agent. Keep PR #3 open until the owner accepts it. [Core Gameplay Foundation proposal](CORE_GAMEPLAY_FOUNDATION.md) is for after acceptance and merge.

## Run or package locally

1. Get the current PR #3 branch and extract it if downloaded as a ZIP. Import `project.godot` in **Godot 4.7.2 Stable Standard (Windows x86_64)**. Use **F5**; if the editor captures function keys, use the separate game window.
2. For the standalone build, install the exact Standard export templates from **Editor → Manage Export Templates**. From the repository root, run the helper with the official `*_console.exe` (or use **Project → Export → Windows x64 → Export Project** to `build/TheLastHaven.exe`).

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\tools\export_windows_acceptance.ps1 -Godot 'C:\Godot\Godot_v4.7.2-stable_win64_console.exe'
   ```

   The helper imports, exports EXE/PCK, adds the license notices and this checklist, and prints the ZIP SHA-256. Unzip `build/TheLastHaven-Windows-x64-acceptance.zip` and launch `TheLastHaven.exe` with `TheLastHaven.pck` beside it, outside the editor. For manual export, keep both files and include `assets/fonts/OFL.txt` and `docs/ASSET_LICENSES.md` with the package.
3. No Windows EXE was built in the sandbox: official Godot downloads redirect to a release-asset host this sandbox could not fetch. The workspace contains the source revision, existing Windows export preset, and unexecuted local packaging helper; it does not contain a verified Windows binary.

## Acceptance checklist

- [ ] **Static rain:** Start in the Court; turn rain off. Walk from the left roofline to the amber door and the right wall. Look at the sky, facade, gutters and bottom foreground at 1× and 2×. No fixed falling-rain streaks should read as precipitation. Amber door reflection, puddles, wet floor, lamps and architecture should remain. Report any fixed streak by screen/location; do not flag attached wall/drain highlights just for being vertical.
- [ ] **F2 and sound:** On gives moving streaks and the approved rain loop; off stops both together. Repeat at least twice without leaving the room. Turn off, enter the warehouse with **W**, exit and confirm off; verify warehouse ambience is unaffected. Restart from defeat and relaunch the executable to verify persistence; turn rain back on and confirm both paths resume. Try Esc pause/resume and F3 shadows independently.
- [ ] **Bat:** Approach the Walker and press **F** in each direction on separate runs. Look for ready, anticipation, swing, impact, follow-through, recovery. At normal speed verify the hit sound, impact FX and Walker recoil coincide with contact, not on key press. A miss or corpse should not emit the infected-hit cue. Move out of reach before contact once; no ghost hit. Try reversing A/D during the motion: the committed swing stays on the starting side, then returns to current facing. Check quick repeated F/LMB/R cannot double-apply a strike or spend a round during the bat action.
- [ ] **Animation and movement:** Walk/run with direction and speed changes, stop at the low case, dodge, jump and land while moving. Observe no extra step right after a landing or at spawn. Poses should not clip or slide obviously. A/D is the only facing input; the camera and collision should behave as in V1.1.
- [ ] **Shooting and reload:** Move cursor behind/above/below the survivor; fire both ways while standing, moving and airborne. Flash should stay at the registered barrel; projectiles stay horizontal and do not pass real obstructions. The low case is shorter than the pistol line. Try partial and empty reload; magazine/reserve accounting remains correct, only the empty reload plays the slide, and HUD stays in reload until complete. Check approved gun reports and footsteps still sound the same.
- [ ] **Persian HUD:** At 1× and 2×, inspect joined Persian letters, RTL ordering and Latin A/D, W, F and F2 labels. Compare health and injury before/after attack, ammo before/after reload, bat label while swinging, contextual W near the door and no prompt far away. No visual HUD redesign is expected.
- [ ] **Package acceptance:** Launch offline without the editor, play the Court → Warehouse → Court round trip, verify the save of the weather preference, and report Godot version, build/branch commit, pass/fail and any exact repro. If exporting, record archive hash alongside the result.

Side smoke covers six bat state/cel pairs, one physics contact on the impact marker, simultaneous registered hit audio node/FX, left and right contact, obstruction, whiff, magazine preservation, jump/landing cadence, projectile preflight, both reload paths, Walker combat, portal state, viewport transform, and F2 toggling visible/simulated rain and audio node state through room changes and in-game restart. Legacy Depot smoke and offline asset checks ran separately.
- **Static/offline:** Native-scale atlas and background visual inspection, distinct bat cells and impact tip registration test, 1100×540 plate geometry and byte-identical central reflection crop. No static rain artwork is composited by runtime code other than the cleaned plate. Approved playback files and audio code are unchanged; all 28 recorded clips retain verified CC0 provenance and voluntary credit in [ASSET_LICENSES.md](ASSET_LICENSES.md). The previous rain is an approved original cue. New bat images are project-original AI-assisted drawings supplied with keyed sources, not public-domain or standalone licensed assets.
- **Not verified here:** Official Windows editor/export, playback through a real audio device, frame pacing, Persian shaping/layout in the official renderer and remaining ambiguous marks at desktop gameplay scale. The headless fallback text server emits a known RTL warning. Animation is deliberately still sparse outside the six bat phases; the impact uses the visible 67 px bat reach rather than the prior invisible 87 px hit reach. No final HUD, more art or core systems were implemented.
